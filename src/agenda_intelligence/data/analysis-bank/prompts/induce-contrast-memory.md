# Induce Contrast Memory

You are extracting reusable reasoning memory by comparing multiple agenda-analysis outputs for the same task.

## Task
Compare successful and failed outputs. Extract at most 5 memory cards that explain what consistently improved decision value and what consistently weakened the analysis.

## Look for

- signal classification differences;
- specificity of actors and mechanisms;
- whether uncertainty was named;
- whether the output was falsifiable;
- quality of watch-next indicators;
- boundary conditions that prevented overconfidence.

## Output format

Use `analysis-bank/MEMORY_FORMAT.md`.
