# Memory: Replace vague monitoring with concrete indicators

- evidence_basis: Derived from repeated output-quality failures where watch-next sections used generic monitoring instead of observable indicators.

## Trigger
The output ends with “monitor developments,” “stay informed,” or similarly vague watch-next advice.

## Pattern
Agent gives a fluent recap and generic implications, but leaves the user without observable indicators.

## Better reasoning
Convert monitoring into named indicators: official text, enforcement action, deadline, regulator guidance, route change, bank behavior, insurance price, market withdrawal, or actor-specific behavior.

## Apply when
The user asks what a public-agenda item means and the answer needs operational or decision value.

## Do not apply when
The user explicitly wants a short headline summary with no monitoring guidance.

## Watch indicators
Documents, deadlines, enforcement events, institutional votes, company behavior, route changes, payment friction, sanctions listings, or regulator guidance.

## Example rewrite
Before: “Companies should monitor developments.”

After: “Watch for regulator guidance, first enforcement action, compliance deadline, and company product redesigns.”
