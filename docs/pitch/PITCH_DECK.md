## Slide 3: The Core Insight — The Model is Not the Product, The Harness Is
- **Models are commoditizing:** Frontier intelligence is rented; open weights (DeepSeek, GLM, Kimi) are collapsing token prices to cents.
- **The Harness is owned:** Real production AI is 10% model and 90% scaffolding:
  - *Context:* Compaction and source assembly.
  - *Permissions:* Strict pre-action gates (what an agent can/cannot do).
  - *Tools:* Structured JSON schemas with zero-tolerance validation.
  - *Verification:* Deterministic claim-to-source linters, audit trails, and rollback.
- **Takeaway:** If your product is a prompt on someone else's API, you are a feature. If you own the verification harness, you own the workflow.

## Slide 4: The Solution — Agenda Intelligence MD
A deterministic evidence-readiness and governance engine across 4 native surfaces:
1. **Deterministic Evidence Linter:** Fast, stateless lexical & schema validator that inspects claims, quotes, numbers, and polarity against source records.
2. **Pre-Action Trust Gate (`agentic_interaction_trust`):** Intercepts A2A requests, demanding missing cryptographic authority, manifests, or step-up confirmation before actions execute.
3. **Guardrail Engine & Auto-Repair Loop:** Automatically builds targeted repair prompts for LLMs when assertions fail.
4. **Cloudflare Serverless Edge Fleet:** Sub-second, globally distributed evaluation running at $0 token cost for pure deterministic checks.
