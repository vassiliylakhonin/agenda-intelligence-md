# Using the fleet's evidence reviews

Start with the [first useful result workflow](../product/first-useful-result.md)
for task selection, inspectable examples, input correction and private session
measurement across the existing fleet.

## Pick a review for the decision

| Service | Useful output | Evidence boundary |
| --- | --- | --- |
| Vizier | Signed authority, policy decision and request-bound receipt | The integrating executor enforces it; caller observations still need a trusted producer. |
| Output Verification | Broken references, literal quote mismatches and missing corroboration | Supplied text is the evidence universe; factual truth and source independence need review. |
| Financial Guard | Unsafe approval/calldata and declared-limit warnings before signing | Stateless advisory; wallet history, authoritative policy and current address status remain unverified. |
| M2M Escrow | Delivery hash/schema/SLO checks and proposed allocation | Caller acceptance needs authentication; no payout is authorized or executed. |
| Critical Minerals | Scoped dossier gaps, stage requirements and owner tasks | Excerpts and declared scope need issuer/authenticity and technical review. |
| Middle Corridor | Required-reference ledger and escalation checklist | Coverage does not approve a booking, shipment or sanctions status. |
| CIS | Public-list name leads, ownership gaps and reviewer tasks | A name match and declared ownership need identity and chain resolution. |
| Gulf Maritime | Voyage dossier gaps and screening leads | Physical vessel identity, AIS facts, ownership and insurance terms need verification. |
| Kazakhstan Market Entry | Staged dossier, open-blocker tasks and committee routing | Document labels do not verify legal, tax, banking or operational readiness. |
| Dual-Use Export | Exact CHPL HS6 reference membership and export dossier gaps | HS is not ECCN; licensing and legal applicability require qualified review. |
| Corridor Assistant | Structured intake and pointers to the relevant dossier gate | Use it to prepare the request and identify missing inputs. |
| Agenda Portal | Discovery, structured routing and illustrative finance scenarios | Financial thresholds are model assumptions; guarantees require proof. |

## Interpret a result

Legacy dossier services publish `source_record_review` with calendar-date and
record-integrity issues. Resolve each indicated source index and obtain the
actual document. The score measures reference-type coverage. Content, issuer,
authenticity and freshness require a separate review; they are explicitly
unverified. An impossible date or a conflicting document ID cannot improve the
score. Reusing a URL alone is allowed because one document can serve multiple
questions; it does not establish independent corroboration.

A complete set can be ready for a human review while actual risk remains unknown.
Caller blockers, name-screen flags and incomplete configured screening constrain
progress. Follow owner tasks and hold execution until the appropriate reviewer
resolves them. Only an enforced authorization integration can control execution.

## Export reference

CHPL uses a dated snapshot, exact six-digit membership and distinct 4A/4B tiers.
Record the reference date and recheck updates for a real shipment. The
[BIS reference](https://www.bis.gov/licensing/country-guidance/common-high-priority-items-list-chpl)
and [OFAC Russia guidance](https://ofac.treasury.gov/faqs/topic/6626) support review
of diversion and applicable financial-institution exposure. A tier alone cannot
establish a license obligation or a sanctions violation.

## Evaluate commercial usefulness

For one real dossier, record which missing documents the reviewer accepted,
which recommendations they rejected, preparation time, and whether the result
changed the next decision. Measure repeat use and paid completion separately
from discovery traffic and saved demos. A small, specific integration can
validate usefulness without buying additional data or adding another worker.
