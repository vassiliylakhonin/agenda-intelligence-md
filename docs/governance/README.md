# Governance

Governance documentation for the **Kazakhstan / Middle Corridor Deal Risk Gate**, the deployed vertical built on the Agenda Intelligence reasoning engine in this repository.

- [ai-policy.md](ai-policy.md) — AI Policy: responsible development, deployment, and use; deterministic rule-based decision logic with no model in the verdict path; mandatory human oversight. Aligned with ISO/IEC 42001:2023.
- [impact-assessment.md](impact-assessment.md) — AI System Impact Assessment: affected parties, risk register, controls mapping, and remediation plan. Aligned with ISO/IEC 42001:2023.

These cover the deployed Gate's governance and boundaries. The reasoning engine itself is documented in the repository root and elsewhere under `docs/`.
