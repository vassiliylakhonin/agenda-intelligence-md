# First-call recovery

- goal: help an integrating client reach an explicit free schema check and inspect the configured trial after an input refusal or unpaid evaluation.
- trusted_evidence: current handler, published input validation/trial contracts, immutable aggregate telemetry for 20–23 October and executable offline recovery tests.
- suspected_unreliable_evidence: malformed requests, anonymous discovery, fingerprints and 402 responses do not establish customers, intent or price sensitivity.
- hidden_assumptions: a visible, executable read-only next step can reduce integration ambiguity; human usefulness and repeat use remain unmeasured. Supplier Desk's local actions are outside server usage.
- intended_next_action: add bounded server-owned recovery metadata across REST/A2A/MCP admission responses, exercise it against the actual handler, then use existing CI and signed deployment gates.
- stop_or_escalate_if: prices, quotas, authentication, payment proof/body binding, protocol rejection or domain results change; submitted content appears in guidance; any failed required gate. Never automatically evaluate, consume trial, pay, retry or send an invitation.

The additive `first_call` object links same-origin contract discovery, schema-only
preflight and, only when enabled, the serving product's trial terms/availability.
Trial inspection reserves nothing. Trial POST is a separate explicit evaluation
and consumes the existing allowance; a trial covers only its named tool.
The original failed or funded request is never replaced with an example.
