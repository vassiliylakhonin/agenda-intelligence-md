# Free-first evidence review

- goal: make the existing Output workflow usable from an agent's first call through a corrected rerun, without manufacturing evidence or paid intent.
- trusted_evidence: current plugin skill/README, actual Worker catalogs and offline 402/text-only reproductions; existing local RAG adapter and shared campaign reservation store.
- suspected_unreliable_evidence: unsigned discovery traffic, historical instrumentation gaps, external strings and synthetic task outcomes. They do not prove demand, source truth or usefulness.
- hidden_assumptions: a narrower task and consistent instructions reduce preparation friction; actual users must still establish usefulness. MCP Apps host support is optional.
- intended_next_action: fix plugin admission/instructions and text compatibility; negotiate supported versions; add a compact evidence-review adapter and optional App over the same guarded quota and deterministic evaluator; verify exact contracts and corrected reruns; publish through existing checked release/deploy workflows.
- stop_or_escalate_if: any regression, changed price/quota/authorization, invented source/support/approval, automatic retries/payment, unsupported new runtime dependency, or rejected production gate. Preserve legacy inputs/tools and a text-only path. Infrastructure changes require actual control of the affected Cloudflare zone; no client impersonation or global protection disablement.

## Interfaces

An answer review accepts an existing answer and original source excerpts. Each
nonblank line is a review unit; inline citations are supplied, not inferred.
Unknown source IDs and missing text remain findings. A clean structural result
requires human review and does not establish truth or authorize publication.

The optional App renders and edits this same input. Opening it, inspecting
allowance or validating JSON cannot reserve an attempt. Evaluation happens only
on an explicit submitted call; all entry points share the existing product's
campaign allowance. A refused rerun must preserve the previous successful result.
