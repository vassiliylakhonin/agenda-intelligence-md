# 1.21.0 — Free-first answer review

Agents can now start Output Verification with an answer and actual source text
using `review_answer`, without preparing claim objects or declaring support
levels. Line-level citation and quotation findings lead to an explicit corrected
rerun. This compact structural review does not assess semantic support or truth.
The existing full claim/evidence audit remains available through `free_trial`.

An optional `open_answer_review` MCP Apps form uses the same tool and guarded
five-attempt campaign quota. Opening, status and schema checks reserve nothing.
Evaluation happens on an explicit click; a failed rerun preserves the previous
completed result. The pinned official SDK is bundled with existing esbuild and
requires no new server framework. Clients without UI retain full JSON text.

Across the fleet, trial descriptions and server instructions lead with the task
and free entry point. Plugin instructions and validation now match its actual
catalog. Paid tools retain separate admission and no automatic payment/retry.

MCP text content now carries the same complete payload as structuredContent.
Legacy initialization selects a supported version. Modern HTTP version, method
and name mirrors are checked before payment or quota admission; supported 2025
handshake clients remain compatible.

Validation includes full repository/Worker checks, golden/failure schema cases,
shared quota and privacy boundaries, a corrected rerun and actual Chromium QA of
the SDK bundle with a local host fixture and strict iframe sandbox. This is not
a claim of every host's compatibility, source truth or external adoption. No live
model API validation or paid settlement was performed. The separate Cloudflare
default-urllib edge restriction still needs administrative access.
