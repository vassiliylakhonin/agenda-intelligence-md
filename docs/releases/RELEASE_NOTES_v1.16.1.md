# Agenda Intelligence MD 1.16.1

MCP Integration Check now works directly after a pip installation: run
`agenda-mcp-check --self-test --strict` to exercise the installed local stdio
server with the pinned official client and a read-only example. This checks
installation; checking your endpoint requires its own trusted configuration.

Ordinary HTTP checks and public Python SDK calls no longer label themselves
as maintainer probes. Use `--owner-test` for your own MCP production checks.
Historical owner-labelled events cannot identify external users and are not
reclassified. Authentication and execution opt-in remain enforced.

Hosted onboarding includes canonical custom-domain links, free-trial
availability and quota recovery, bounded optional feedback, and the one-claim
citation-review form. Bundled browser summaries remain self-contained after
Wrangler name preservation. Supplied evidence remains caller-reported, and
clean lint requires human review.

Interaction Trust links to concrete request-bound execution integrations and
the maintained Vizier Worker deployment adapter. The public evidence review
page alone does not enforce execution restrictions. Installation and local
checks establish tested behavior, not customer demand or a security guarantee.

Existing service schemas, prices, authorization and atomic trial limits are
preserved. Registry remotes use the registered custom domains, retaining old
endpoint aliases and signing identities.
