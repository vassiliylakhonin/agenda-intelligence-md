# 1.21.2 — Package description and hosted workflow refresh

Install with `python -m pip install --upgrade "agenda-intelligence-md==1.21.2"`.
The PyPI description now starts with a complete Python example that runs without
a repository checkout, model key or network after installation. Documentation
links are absolute and pinned to this release.

The description also points to the already deployed hosted workflows:

- REST/A2A/MCP input/payment refusals expose a free schema-preflight and configured
  trial-inspection path. Text-only MCP clients and the retained integration keep
  the guidance. Inspection consumes nothing; evaluation is explicit.
- Supplier Evidence Desk prepares local supplier checklists, owner requests,
  bounded PDF/DOCX excerpts, saved versions and reviewer PDF/source ZIP/JSON
  handover. Documents stay in the browser. This is a separate hosted workspace,
  not a new Python-wheel document-processing API.

No public schema/tool removal, domain behavior, price, quota or authorization
change. Core packet completeness still does not establish factual truth or
permission to act. Synthetic tests, discovery and owner checks are not evidence
of customer usage, paid demand or reviewer acceptance. Live model API validation
and settlement are not claimed.
