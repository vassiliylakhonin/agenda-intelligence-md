# Baselines

Committed reference reports from `agenda-intelligence bench`, regenerated by:

```bash
python evals/run_benchmark.py \
    --md evals/baselines/source-backed.md \
    --out evals/baselines/source-backed.json
```

These are **structural / evidence-discipline** numbers on the bundled examples.
They do not verify factual truth and they do not represent benchmark results
on real agent output. For that, see the benchmark roadmap in
[`docs/evaluation.md`](../../docs/evaluation.md).

The committed reports are deterministic given the inputs in `examples/` and
the heuristic rubric in `agenda_intelligence.eval`. If a change moves these
numbers, the change touches the rubric or the examples on purpose; reflect
that in the commit message and regenerate the files.
