# Agenda Intelligence Repository Stack

Agenda Intelligence MD is the product/runtime repository in a four-repo stack.

| Layer | Repository | Role |
|---|---|---|
| Product runtime | `agenda-intelligence-md` | Core service layer, MCP / HTTP / A2A surfaces, schemas, evidence audit, scoring, and vertical worker contracts |
| Reasoning method | `global-think-tank-analyst` | Strategic-risk reasoning method loaded by the product shell |
| Regional specialist | `central-asia-caspian-hybrid-intelligence-skill` | Central Asia, Caspian, Kazakhstan, Middle Corridor regional lens |
| Regional specialist | `gulf-middle-east-hybrid-intelligence-skill` | Gulf, Middle East, Iran, maritime chokepoint regional lens |

## Interpretation

The core commercial workflow is reusable evidence-readiness and trust-routing. The regional skills and vertical workers are modules or portfolio proofs, not proof that each vertical has buyer demand.

For the next validation cycle, prioritize redacted project-room evidence-readiness tests over new vertical workers.
