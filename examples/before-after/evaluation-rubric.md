# Evaluation Rubric for Agenda Analysis

Use this rubric to judge whether Agenda-Intelligence.md improved an agent output.

| Criterion | Weak output | Strong output |
|---|---|---|
| Signal classification | Does not say whether the item is noise, weak signal, signal, structural shift, or trigger event | Classifies the item and explains what would upgrade/downgrade it |
| What changed | Repeats what happened | Identifies the decision-relevant delta |
| Actor specificity | Says “companies,” “governments,” or “stakeholders” generically | Names affected actor groups and why each is exposed |
| Mechanism | Uses vague phrases like “could impact” | Explains the channel: law, enforcement, logistics, finance, market access, legitimacy, security, etc. |
| Uncertainty | Hides uncertainty or adds generic caveats | Names the main uncertainty and why it matters |
| Falsifiability | Gives no way to test the view | States what would confirm, weaken, or falsify the assessment |
| Watch-next indicators | Says “monitor developments” | Names concrete indicators, documents, actors, deadlines, or behaviors to watch |
| Decision value | Sounds informed but does not change action | Helps decide whether to act, wait, escalate, prepare, or ignore |

## Quick score

Score each criterion 0–2:

- **0** — missing or generic
- **1** — partially present
- **2** — specific and decision-useful

Interpretation:

- **0–5:** mostly summary
- **6–10:** usable orientation
- **11–16:** decision-useful agenda analysis
