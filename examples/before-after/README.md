# Before / After Examples

These examples show the point of Agenda-Intelligence.md.

Without the protocol, agents often produce fluent summaries with vague implications.
With the protocol, the output classifies signal, separates fact from assessment, names uncertainty, and ends with watch-next indicators.

## Examples

- [EU AI Act implementation signal](eu-ai-act.md)
- [Red Sea shipping disruption](red-sea-shipping.md)
- [Sanctions routing through Central Asia](sanctions-routing.md)

## Pattern

```text
Before: recap → generic implications → “monitor developments”
After: signal classification → what changed → affected actors → uncertainty → scenarios → watch-next indicators
```
